

# ভোটার নং সার্চ UI আপডেট

## লক্ষ্য
স্ক্রিনশটের মতো লেআউট - সেন্টার্ড টাইটেল, আন্ডারলাইন ইনপুট, ফুল-উইড্থ বাটন। তবে কালার থিম আগের মতোই (সবুজ/primary) থাকবে।

## বর্তমান vs নতুন ডিজাইন

```text
বর্তমান:                          নতুন (স্ক্রিনশটের মতো):
+---------------------------+      +---------------------------+
| 🎴 ভোটার নং দিয়ে সার্চ     |      |                           |
|                           |      |    ভোটার নং দিয়ে সার্চ     |
| [____input____] [সার্চ]   |      |        (centered)         |
+---------------------------+      |                           |
                                   |   ___________________     |
                                   |   (underline input)       |
                                   |                           |
                                   |   [=== সার্চ করুন ===]    |
                                   |   (full-width button)     |
                                   +---------------------------+
```

## পরিবর্তনসমূহ

### VoterNoSearch.tsx
- CardHeader/CardTitle সরিয়ে শুধু CardContent ব্যবহার
- টাইটেল সেন্টার করা (`text-center`, বড় সাইজ)
- ইনপুট স্টাইল পরিবর্তন:
  - আন্ডারলাইন স্টাইল (`border-0 border-b-2`)
  - টেক্সট সেন্টার করা
  - বড় সাইজ
- বাটন ফুল-উইড্থ করা (`w-full`)
- ফর্ম লেআউট ভার্টিকাল করা (`flex-col`)
- কার্ডে বেশি প্যাডিং ও rounded কর্নার

## কালার থিম (একই থাকবে)
- বাটন: `bg-primary` (সবুজ)
- বর্ডার: `border-primary`
- টেক্সট: `text-primary`
